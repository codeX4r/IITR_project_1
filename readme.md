# Multi-Agent Analytics Assistant

## Overview

The Multi-Agent Analytics Assistant is an AI-powered data analytics platform that utilizes multiple AI agents to automate dataset analysis, generate insights, and answer user queries. Built using CrewAI, Ollama, and Streamlit, the application enables collaborative problem-solving through Large Language Models (LLMs).

---

## Features

- Multi-Agent Collaboration
- Dataset Upload and Analysis
- Statistical Summary
- Missing Value Detection
- Correlation Analysis
- Data Visualization
- Natural Language Querying
- YAML-based Agent Configuration
- Local LLM Integration using Ollama
